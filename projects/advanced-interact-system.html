La idea

Una interacción que no hay que reinventar en cada proyecto.

Este sistema parte de un flujo sencillo entre jugador, objeto y feedback. La intención es tener una base entendible desde el inicio, que permita concentrar el trabajo en la mecánica concreta y no en resolver de nuevo la infraestructura.

Una arquitectura diseñada para crecer cuando lo haga la idea de juego.
